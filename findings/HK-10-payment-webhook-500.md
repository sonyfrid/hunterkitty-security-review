# HK-10. Кривое тело запроса оплаты даёт 500

| | |
|---|---|
| Категория | OWASP API Top 10: API8 Security Misconfiguration (обработка ошибок) |
| Серьёзность | Low, CVSS 3.1 ≈ 2.7 (AV:N/AC:L/PR:L/UI:N/S:U/C:N/I:N/A:N) |
| Компонент | запрос ссылки на оплату PRO |
| Кто нашёл | аудит 11.11.2026, разбор кода |
| Статус | исправлено 17.11.2026 |

## Что не так
Один обработчик оплаты читал JSON напрямую, без общей обёртки. Сломанное тело запроса роняло обработчик с 500. Сейчас оплата выключена (всё бесплатно), поэтому вживую не проявлялось.

## Как исправлено
Обработчик читает тело через ту же обёртку, что и остальные: на сломанный JSON отвечает 400 с понятной ошибкой.

## Проверка
Проверено разбором кода: обработчик теперь использует общую обёртку, которую покрывают тесты остальных маршрутов. Отдельного теста на этот маршрут пока нет.

## Вывод
Все входы должны идти через одну проверенную обёртку. Одно место «по-быстрому» и есть то, что найдут первым.
