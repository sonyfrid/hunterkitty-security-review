# HK-06. Бесплатный PRO через занятый чужой ник

| | |
|---|---|
| Категория | OWASP Top 10: A01 Broken Access Control, A07 Identification and Authentication Failures |
| Серьёзность | Medium, CVSS 3.1 ≈ 4.3 (AV:N/AC:L/PR:L/UI:N/S:U/C:N/I:L/A:N) |
| Компонент | выдача PRO друзьям |
| Кто нашёл | аудит 11.11.2026, разбор кода |
| Статус | исправлено 17.11.2026 |

## Что не так
Друзьям PRO выдавался по списку @ников. Ник в Telegram можно сменить, освободившийся ник может занять другой человек.

## Чем опасно
Кто занял ник друга, получал платный доступ навсегда. Сейчас всё бесплатно, но как только PRO станет платным, это прямая потеря денег.

## Как исправлено
Список хранит tg_id. Он не меняется никогда, сменить его нельзя.

## Проверка
`tests/test_privileges.py`: человек с ником друга, но другим id ничего не получает, друг после смены ника доступ сохраняет. Уязвимая версия даёт PRO чужому (`xfail`).

## Вывод
Идентифицировать надо по неизменяемому id, а не по отображаемому имени.
