# HK-07. Ссылки `javascript:` в кнопке «открыть вакансию»

| | |
|---|---|
| Категория | OWASP Top 10: A03 Injection (XSS через схему ссылки) |
| Серьёзность | Low, CVSS 3.1 ≈ 3.5 (AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:L/A:N) |
| Компонент | Mini App и сообщения бота |
| Кто нашёл | аудит 11.11.2026 (QA-08), враждебные данные на стенде |
| Статус | исправлено |

## Что не так
Адрес вакансии приходит из чужих постов и сайтов. Mini App передавала его в `Telegram.WebApp.openLink` без проверки схемы, туда доходили `javascript:` и `data:`.

## Чем опасно
Telegram сам ограничивает такие ссылки, поэтому живьём вреда не было. Но надеяться на чужую защиту нельзя: поведение клиентов разное и может поменяться.

## Как исправлено
Открываем только `http(s)`:
```js
if (!url || !/^https?:\/\//i.test(url)) return;
```
Такой же фильтр стоит на ссылках в сообщениях бота.

## Проверка
`js/openUrl.test.js` (node:test): `javascript:`, `data:`, `file:` не открываются, обычные ссылки и t.me открываются, уязвимая версия пропускала `javascript:`.
