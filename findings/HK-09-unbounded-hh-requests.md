# HK-09. Мгновенный поиск без потолка запросов к внешнему сайту

| | |
|---|---|
| Категория | OWASP API Top 10: API4 Unrestricted Resource Consumption |
| Серьёзность | Medium, CVSS 3.1 ≈ 4.3 (AV:N/AC:L/PR:L/UI:N/S:U/C:N/I:N/A:L) |
| Компонент | мгновенный поиск по сайту вакансий после смены фильтров |
| Кто нашёл | аудит 11.11.2026, разбор кода |
| Статус | исправлено 17.11.2026 |

## Что не так
После смены фильтров сервис сразу ищет вакансии на большом сайте вакансий. Число запросов зависело от профиля: десятки профессий и городов давали десятки запросов подряд.

## Чем опасно
Один пользователь с большим профилем мог вызвать у внешнего сайта капчу или блокировку. Источник перестал бы работать для всех пользователей сервиса. Это отказ в обслуживании чужими руками.

## Как исправлено
Потолок: не больше 12 запросов на один мгновенный поиск, остальное доберёт обычный плановый сбор.

## Проверка
Проверено разбором кода после исправления. Отдельного автотеста на потолок пока нет, он в планах.

## Вывод
Внешний источник это общий ресурс. Лимиты нужны не только на свой API, но и на то, как сервис ходит наружу.
