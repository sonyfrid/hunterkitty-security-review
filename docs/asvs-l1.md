# OWASP ASVS 4.0.3, уровень 1: что выполнено

Самооценка 18.11.2026 по главам, которые относятся к Mini App и его API: V2, V3, V4, V5, V8, V9, V13, V14.
Статусы: **да**, **частично**, **нет**, **н/п** (не применимо, с причиной). У каждого пункта есть доказательство: тест, находка или проверка.

Ссылки на тесты:
- `e2e/access` и `e2e/sqli`: [hunterkitty-e2e/tests/api](https://github.com/sonyfrid/hunterkitty-e2e/tree/main/tests/api), API-тесты на стенде с настоящей PostgreSQL;
- `demo/...`: тесты в этом репозитории;
- `product/...`: тесты в коде продукта (закрыт), описаны здесь.

## V2. Аутентификация
| Пункт | Требование, кратко | Статус | Доказательство |
|---|---|---|---|
| V2.1.x | Требования к паролям | н/п | входа по паролю нет, аутентификацию делает Telegram, сервис проверяет его подпись |
| V2.2.1 | Защита от автоматизированного перебора | частично | лимит запросов на пользователя, 429 (проверено на стенде); перебирать нечего: без токена бота подпись не подделать |
| V2.5.x | Восстановление доступа | н/п | учётные данные хранит Telegram |
| V2.10.x (L2) | Учётные данные сервисов не в коде | да | токены и ключи только в файле окружения на сервере, права только у владельца сервиса |

## Итог
Из применимых пунктов L1 большинство выполнено и закрыто тестами. Открыто: повтор initData (HK-11), проверка Content-Type, HSTS, заголовок `Server`, шифрование и доступ к резервным копиям, автоматическое сканирование зависимостей. Все пункты в плане, ни один не даёт доступа к чужим данным без предварительной кражи подписи или доступа к серверу.
